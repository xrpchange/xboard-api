```
│                 │     │                 │     │                 │
│ • Доска         │     │ • Доска         │     │ • Доска         │

                    └─────────────────────────┘
```

## 🌐 Что такое УЗЕЛ?

**Узел** - это независимая **доска объявлений** P2P обменов криптовалют.

Каждый узел:
- Имеет свою **базу данных** с объявлениями
- Управляется **своим провайдером**
- Имеет свои **API endpoints**
- Независим от других узлов

## 📍 Точки входа одного узла

Один узел может иметь **несколько точек входа** для разных целей:

### Узел XRPChange имеет:

**Для клиентов (XBoard API):**
- `api.xrpchange.site` - реальные деньги
- `sandbox.api.xrpchange.site` - для тестов
- `dev.api.xrpchange.site` - для разработчиков

**Для блокчейна (Core API):**
- `api.core.xrpchange.site` - реальный блокчейн
- `sandbox.api.core.xrpchange.site` - тестовый блокчейн

**Важно:** Все эти URL - это **части ОДНОГО узла XRPChange**, а не отдельные узлы!

## 🔮 Будущее - множественные узлы

### Сейчас:
```
XBoard Client → XRPChange (единственный узел)
```

### В будущем:
```
XBoard Client → XRPChange (узел 1)
             → AnotherExchange (узел 2)
             → CryptoExchange (узел 3)
             → YourExchange (узел 4)
```

Каждый узел - это **независимый провайдер** с собственной доской объявлений.

## 🎯 Преимущества для пользователя

### Как в почтовом клиенте:
- Один клиент (Outlook) → Много почтовых ящиков (Gmail, Yahoo, Outlook)
- Удобно управлять всеми в одном месте

### Так же в XBoard:
- Один клиент (XBoard) → Много бирж (XRPChange, AnotherExchange, etc.)
- Удобно искать объявления на всех биржах сразу
- Сравнивать курсы разных провайдеров

## 💾 Хранение узлов

### В базе данных:
- Таблица `nodes` хранит информацию обо всех доступных узлах
- Клиент запрашивает список узлов при запуске
- Пользователь видит и выбирает узлы в настройках

### Типы узлов:

**Обязательные** (`is_required = true`):
- Всегда подключены
- Нельзя отключить
- Базовая функциональность

**Опциональные** (`is_required = false`):
- Подключаются по желанию
- Можно отключить в настройках
- Дополнительные возможности

## 📱 Реализация в клиенте

### При запуске:
1. Загрузить список узлов из API
2. Подключить обязательные узлы
3. Восстановить выбор пользователя (какие опциональные узлы включены)
4. Проверить доступность всех узлов

### В настройках:
- Показать список всех узлов
- Обязательные отмечены и неактивны (нельзя отключить)
- Опциональные можно включить/отключить
- Индикатор статуса (online/offline)
