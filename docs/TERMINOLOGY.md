# Терминология для партнёров и документации

Документ задаёт **бизнес-понятия** и их соответствие техническим терминам. В общении с партнёрами и в пользовательских интерфейсах используйте эти понятия.

## Основные понятия

| Бизнес / пользователь | Технический термин (код, API) | Описание |
|------------------------|------------------------------|----------|
| **Обменник** | Node | Один пункт обмена: платформа с собственным API, доменом, лотами. Соответствует одной записи в таблице `nodes`. |
| **Сеть обменников** | Список узлов (nodes), «кластер» | Набор доверенных обменников, доступных пользователю или партнёру. Определяется данными из таблицы `nodes` и отношениями доверия (is_trusted, mutual trust). В интерфейсе — «Обменники», «Доверенные обменники». |
| **Клиент** | Client, XBoard Client | Приложение для пользователей и партнёров: поиск лотов, создание лотов, управление эскроу-токенами, настройка подключения к обменникам. Может быть мобильным (Android), веб или другим. Подключается к API обменников из сети обменников. |

## Правила использования

- В **документации для партнёров** и в **пользовательских текстах** (интерфейс, сообщения) предпочтительно: **обменник**, **сеть обменников**, **клиент**.
- В **коде и технической документации** (API, БД, комментарии) допустимы технические термины: node, nodes, client; при первом упоминании в документе можно указывать соответствие: «node (обменник)», «сеть обменников (nodes)».
- Избегайте в пользовательских и партнёрских материалах чисто технических формулировок: «узел», «кластер», «нода» — заменяйте на **обменник** и **сеть обменников**.

## Кратко

- **Обменник** = одна площадка обмена (запись в `nodes`).
- **Сеть обменников** = доступный пользователю/партнёру набор таких площадок (данные из `nodes` и доверие).
- **Клиент** = приложение, через которое пользователь работает с сетью обменников (поиск, лоты, токены).
