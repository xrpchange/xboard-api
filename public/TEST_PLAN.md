# XBoard Client — План тестирования

**Версия документа:** 1.0  
**Для тестировщика:** первое знакомство с приложением  
**Платформа:** Android

**Ссылки:**
- **APK:** https://sandbox.api.xdexboard.com/xboard-client-debug.apk  
- **План тестирования (этот документ):** https://sandbox.api.xdexboard.com/TEST_PLAN.md  

---

## 1. Что это за приложение

XBoard Client — клиент для сети обменников криптовалюты. Пользователь может:
- искать лоты обмена по фильтрам (страна, валюты, банки);
- создавать свои лоты обмена;
- управлять обменниками (узлами) и эскроу-токенами;
- настраивать язык, тему, API-режим (Production/Sandbox).

| # | Действие | Ожидаемый результат |

## 4. Экран «Поиск» (Search)

**Назначение:** Поиск лотов обмена. Покупатель указывает: чем платит, что хочет купить, опционально бюджет.

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 4.1 | Открыть экран Поиск | Видна карточка «Тестовая группа» или «Группа» (зелёная/оранжевая) |
| 4.2 | Проверить фильтры | Есть поля: Страна, Банк получателя, Принимает от банка, Плачу, Хочу купить, Бюджет |
| 4.3 | Нажать «Искать» без выбора страны | Кнопка «Искать» неактивна (disabled) |
| 4.4 | Выбрать страну | В списке есть страны, выбор сохраняется |
| 4.5 | Выбрать «Плачу» и «Хочу купить» (разные валюты) | Кнопка «Искать» становится активной |
| 4.6 | Нажать «Искать» | Показывается индикатор загрузки или результаты |
| 4.7 | При наличии результатов | Карточки лотов: валюта в формате «USDT (Stellar)» (не usdt_stellar) |
| 4.8 | Проверить блок AML в карточке лота | AML всегда показан оранжевым: «AML: X%» или «AML: Не учитывается» |
| 4.9 | Нажать кнопку ℹ (info) рядом с AML | Открывается диалог с предупреждением об AML и ссылками |
| 4.10 | Нажать ссылку в диалоге AML | Открывается браузер по ссылке |
| 4.11 | Выбрать группу (карточка «Тестовая группа») | Открывается диалог выбора/добавления группы |
| 4.12 | Ввести бюджет и искать | Лоты с мин. суммой ≤ бюджету подсвечиваются (например, «Укладывается в бюджет») |

## 5. Экран «Создать лот» (Create Lot)

**Назначение:** Размещение нового лота обмена.

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 5.1 | Перейти в «Создать лот» | Открывается форма создания лота |
| 5.2 | Проверить обязательные поля | Обменник, Отдаю валюту, Получаю валюту, суммы |
| 5.3 | Выбрать криптовалюту (например XMR) | Если доступно — поле AML появляется с оранжевым оформлением |
| 5.4 | Нажать ℹ у поля AML | Открывается диалог предупреждения AML |
| 5.5 | Попытаться создать лот без токена | Показывается сообщение о необходимости добавить эскроу-токен |
| 5.6 | Заполнить все поля и нажать «Разместить лот» | При успехе — возврат на экран Поиск; при ошибке — сообщение об ошибке |

---

## 6. Экран «Обменники» (Nodes)

**Назначение:** Управление списком обменников (включить/выключить, добавить).

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 6.1 | Открыть «Обменники» | Список обменников загружается |
| 6.2 | Проверить переключатели | Можно включать/выключать обменники |
| 6.3 | Отключить все обменники | При поиске лотов — пустой результат или предупреждение |
| 6.4 | Включить обменники обратно | Поиск снова возвращает лоты |

---

## 7. Экран «Токен» (Token)

**Назначение:** Управление эскроу-токенами для доступа к API обменников.

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 7.1 | Открыть «Токен» | Список токенов или предложение добавить токен |
| 7.2 | Проверить создание/импорт токена | Диалоги работают без падений |

---

## 8. Экран «Настройки» (Settings)

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 8.1 | Открыть «Настройки» | Видны разделы: язык, тема, API и т.д. |
| 8.2 | Сменить язык (English / Русский) | Интерфейс переключается на выбранный язык |
| 8.3 | Сменить тему (светлая/тёмная/системная) | Тема применяется |
| 8.4 | Выбрать API endpoint (Sandbox / Production) | Режим переключается; в Sandbox — оранжевая индикация |
| 8.5 | Проверить предупреждение Sandbox | Видно предупреждение, что в sandbox нет реальных денег |

---

## 9. Регрессия и стабильность

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 9.1 | Переключаться между экранами 5–10 раз | Приложение не падает |
| 9.2 | Поворачивать экран | Контент отображается корректно, без обрезки |
| 9.3 | Свернуть приложение и вернуться | Состояние сохраняется, нет вылетов |
| 9.4 | Отключить интернет и выполнить поиск | Показывается ошибка, приложение не падает |

---

## 10. Отчёт о тестировании

При найденных дефектах указывать:
- шаг из плана (например, 4.8);
- устройство и версию Android;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- скриншот (по возможности).
